## "(X s and Y s)" after two named items: pair each figure with its name, checked against the record; "the build" is the app in design/ §10

In design/ test items, a pair of figures in brackets after two names ("distinct headings and distinct links ... (1.41 s and 1.02 s)") does not show which figure goes with which name, and a second-language reader cannot check it. Write each figure with its name ("1.41 s for distinct headings and 1.02 s for distinct links"). Check the pairing in the device record first. Do not trust the order of the names. Found on #668 (j317, f9af1869f). The record was apps/human-android/device-runs/2026-11-13-samsung-a40-back-during-opening.md.

In the same file, "the build" means the app as built ("The build measures and reports"). "Waits for the build to end", written about building the reader's first screen, collided with that meaning. Name the process instead ("until the first screen is built").

**Why:** the cold read flagged the unpaired figures. Neither pass had caught them, because each pass read the figures in the author's order.
**How to apply:** check every bracketed pair or list of figures that follows a list of names. Related: [[name-the-referent]], [[word-against-the-where-cell]].
