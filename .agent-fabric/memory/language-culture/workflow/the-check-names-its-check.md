## a bare "the check" in a spec's carry list, beside other checks, names which one; rename my own "the check that ..." first

In an acceptance item that lists several carried checks, a bare "the check" has more than one referent. On #683 (design/2026-11-04-long-message.md, A5), the author wrote "owed before the check is called passed". Next to it was my own j327 wording, "the check that no frame shows the bar". A reader could take "the check" to mean that check, A5 on the desktop as a whole, or distinct headings past the first turn. The author meant distinct headings past the first turn (REPLY 01a1e25f, 2026-11-16).

**Why:** a cold read does not catch this, because each candidate reads as fine. Only a reader who counts the checks in the item sees the ambiguity. My earlier wording had added one of the candidates.

**How to apply:** when a text says "the check" or "the test", count the checks in the same item. If there is more than one, ask the author which they mean, and then write that check's name in the sentence. Write the name in full where "the check" stood, even when it repeats a phrase earlier in the same item. On #683 (e0b333127) the item reads "distinct headings past the first turn on a host that is not loaded, which is needed before distinct headings past the first turn on the desktop can be called passed". The cold read suggested "it" for the second phrase, and I withdrew that, because "it" brings back the ambiguity. Rename my own phrase to the record's term ("a frame-level test") so that it does not compete with the author's "the check". Related: [[name-the-referent]], [[test-step-words-that-collide]].
