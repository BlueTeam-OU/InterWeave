## run-record counts in design/ prose — "N runs of M rounds each" across several shapes; "N judged rounds of M"

In a runs list that covers several test shapes, "three runs of three rounds each" read as three runs in all. The record had three runs a day, each with three rounds of each shape. "Fifteen judged rounds of seventeen" read as fifteen judged. Write "three runs, each with three rounds of each shape (nine rounds of each shape a day)" and "fifteen of the seventeen judged rounds" (#683 j327, 616b7f297). Check each count against the record's table: per shape, per run or per day.

**Why:** a second-language reader takes "each" to belong to the nearest noun and "of M" to name a total. Then the later "nine rounds of nine" looks wrong.

**How to apply:** for every count in a runs list, name the unit it counts, and phrase it as "N of the M <unit>". See [[pair-figures-name-their-shapes]] and [[every-value-a-step-reads]].
