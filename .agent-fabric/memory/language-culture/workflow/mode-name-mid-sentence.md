## "had the mode stay reachable" parses as causative; write "was in stay-reachable mode"; a passive refusal is not the process's act

A lowercase mode name with a verb in it, placed after "had the mode", reads as "have X do Y": "That run had the availability mode stay reachable" (human-client-android.md, #659, 2026-11-13). Write "That run was in stay-reachable mode", as the document's own test list does. In the same pass, "the process that refused the restart" made the process the one who refused. The start was refused inside it, so the text became "the process in which the restart was refused".

**Why:** a second-language reader takes the first parse the grammar offers.
**How to apply:** where a mode or state name has a verb in it, read it in its place in the sentence; give a passive refusal its real agent, or none. Related: [[name-the-referent]], [[start-is-a-taken-word]].
