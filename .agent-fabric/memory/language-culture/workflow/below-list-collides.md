## the list below" in the Android identity note collides with "the full list" screen; say "the focus rules below

In design/2026-10-19-android-identity.md, "the full list" is a screen (§4 item 4). So "as the list below says" in §8 can be read as pointing at that screen. On PR #645 (j299, a83cdc253) it was changed to "as the focus rules below say". The same pass replaced "Return" with "Enter", which is what the rest of the note calls that key.

**Why:** a defined noun of the product turns a generic word into a second referent, the same kind of collision as "keep" beside Keep.

**How to apply:** in a spec that defines "list", "row", "stop" or "chip" as a thing, name a run of bullets by its subject ("the focus rules below"), never as "the list". See [[name-the-referent]] and [[workflow-carried-2026-10-10]].
