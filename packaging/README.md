# Packaging

Platform packaging metadata/scripts land here with Stage 19, after the corresponding application exists; `macos/` and `windows/` are landing zones today. `android/` holds the Android release run (ADR-0057): the order of the tagged run's steps, each a script in `tools/ci/`, and the signing key's variables. `linux/` holds the daemon's and an automated client's systemd user-unit templates (pulled forward for Linux by Stage 20, plan §28 step 4) and, since Stage 19 (§22), the account-local `install.sh` and `uninstall.sh` that place and remove them with the three executables; `tests/desktop-e2e/tests/user_units.rs` drives both under a user manager. `claude-plugin/interweave/` is built: the Claude Code plugin that starts the Channel bridge (`apps/claude-channel`, Stage 16). Keep packaging separate from transport/domain crates.
