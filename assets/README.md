# Assets

InterWeave's image assets and where each came from. Every image in the
repository is listed here by path; a new one is added in the same change
that adds it, and an image no longer used is marked unused, not deleted.

## The icon

Two strands, teal and amber, braid across a navy tile and cross twice:
the mark of a transport that weaves two parties together. It is drawn in
agent-fabric's visual family — the same navy tile, the same amber and
teal strands, the same over-and-under crossing as agent-fabric's own
icon — so the two read as related at a glance.

Every file below is generated by [`generate_icon.py`](generate_icon.py)
from one geometry; change the geometry there and run it from the
repository root (`python3 assets/generate_icon.py`), never edit a
generated file by hand. The PNG needs `rsvg-convert` (librsvg); the
committed one was made with rsvg-convert 2.61.4, and another librsvg
version may anti-alias it differently, which shows as a changed PNG.

**Origin.** Drawn by brand-comms on 2026-10-11, derived from
agent-fabric's `docs/assets/agent-fabric-icon.svg` at commit `9914eeb4`
(Apache-2.0): its palette (navy `#232c63` to `#141a3a`, amber `#ffb547`,
teal `#2ec4b6`), its rounded tile and its cased, over-and-under strands.
The direction was chosen by the owner the same day.
