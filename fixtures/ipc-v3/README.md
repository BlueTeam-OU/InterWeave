# ipc-v3

IPC frame fixtures of major 3 (ADR-0067 decision 7, the derived EndpointId): the payload-fit invariant and the golden frames. Major 2's fixtures were these files under `fixtures/ipc-v2/` until the Stage 22 batch that opened major 3 regenerated them; no build serves major 2, so no vector of it is kept.

`ipc-v3-payload-fit.json` — the payload-fit invariant, both directions, as the 4-byte big-endian frame length prefix the wire would emit. Every EndpointId is the derived id, exactly 52 characters (`endpoints/endpoint-id` 2.0.0), so the maximal `send-params` body is 66,084 bytes and the maximal `message-received` body 66,222, each leaving ~64 KB under the 131,072-byte ceiling. Measured over the schema-defined object; the outer request/event envelope is modelled by no schema and is reported as headroom rather than invented.

`ipc-v3-frame-golden.json` — seventeen whole frames under `ipc-v3-length-prefix-v1`: the 4-byte big-endian length then the body as compact UTF-8 JSON, one per frame class of `ipc/frame` 3.0.0 (hello in three shapes, hello_response, close in two, request in three, response in two, cancel, two event types, server_state, ping, pong). Every body validates against the frame schema, a request's (method, params) pair against `ipc/request` and an event's (event_type, data) pair against `ipc/event`; the non-ASCII close message pins that the prefix counts UTF-8 bytes. The form frozen is serde_json's compact writer with `preserve_order`; the contract pins no canonical JSON, so a reader accepts any object. `hello-unsupported-major` is a 2.13 hello, answered by `close-version-incompatible` naming major 3.

**TEST-ONLY endpoint ids.** Every EndpointId a golden body carries is the derived id of a public test seed, named in the vector's `test_only_endpoints` (`{JSON pointer into the body: name}`): `tests/support`'s `endpoint_keys::endpoint_id(name)`, whose seed is `SHA-256("interweave/test-only/endpoint-key/v1\0" ‖ name)`. `tools/checks/verify_fixture_vectors.py` recomputes each id from its name, refuses an EndpointId no name derives (a label among them), and holds a `hello_response` to major 3 and transport contract `3.0`. Anyone can recompute the secret from the name: these keys stand for nothing outside a test.

Handshake, error-precedence and endpoint-claim behaviour is not a vector and belongs in `tests/ipc-v2` (the test crate keeps its name on major 3).
